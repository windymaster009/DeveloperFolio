# Kevin Nhim — DeveloperFolio

Kevin's personal software developer portfolio.

This project is directly based on **DeveloperFolio** by Saad Pasta:
https://github.com/saadpasta/developerFolio

It preserves the DeveloperFolio layout, sections, animations, dark mode, cards and overall experience, while replacing the original sample content with Kevin's information and adding automatic GitHub analysis.

## Added for this portfolio

- Automatic public-project count
- Automatic programming-language count
- Automatic technology/framework detection
- Project count per detected technology
- Automatic featured/recent GitHub project cards
- Raspberry Pi + PM2 production deployment
- Port 3030 static production server
- GitHub Actions build validation

## Local development

```bash
npm install --legacy-peer-deps
npm start
```

## Build

```bash
npm install --legacy-peer-deps
npm run build
```

The build script refreshes `public/profile.json` and `public/github-stats.json` from GitHub.

An optional `GITHUB_TOKEN` increases GitHub API limits. It is used only by the Node build-time fetch script.

## Raspberry Pi

```bash
cd ~/DeveloperFolio
chmod +x scripts/deploy-pi.sh
./scripts/deploy-pi.sh
```

The portfolio is served by PM2 at:

```text
http://0.0.0.0:3030
```

For Cloudflare Tunnel, route the hostname to:

```text
http://localhost:3030
```

## Customization

Most personal content lives in:

```text
src/portfolio.js
```

GitHub statistics are generated by:

```text
fetch.js
```
